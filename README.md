# Pós-Graduação em Engenharia de Automação de Processos com IA 🤖

Este repositório documenta a minha jornada de aprendizagem e desenvolvimento prático na **Pós-Graduação em Engenharia de Automação de Processos com Inteligência Artificial**, ministrada pela **Data Science Academy (DSA)**.

Aqui concentro anotações, exercícios de fixação e projetos desenvolvidos ao longo dos módulos, com foco na aplicação real de IA para otimização de fluxos de trabalho.

## 🎯 Objetivos
- Dominar ferramentas de **Automação Inteligente** e **Engenharia de IA**.
- Desenvolver e implementar **Agentes Autônomos**.
- Criar soluções utilizando **LLMs (Large Language Models)** e **RAG (Retrieval-Augmented Generation)**.
- Construir um portfólio sólido de automação de processos.
