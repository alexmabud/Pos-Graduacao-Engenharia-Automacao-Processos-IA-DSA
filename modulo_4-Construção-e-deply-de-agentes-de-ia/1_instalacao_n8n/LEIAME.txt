# Preparando o Ambiente de Trabalho

########## Usuário Mac/Linux ##########

# 1- Abra o Docker Desktop e mantenha a janela aberta para inicializar o Docker Engine.

# 2- Abra o terminal, navegue até a pasta com os arquivos e execute os comandos abaixo:

chmod +x dsa-start-n8n.sh
./dsa-start-n8n.sh


########## Usuário Windows ##########

# 1- Abra o Docker Desktop e mantenha a janela aberta para inicializar o Docker Engine.

# 2- Abra o Power Shell como administrador, navegue até a pasta com os arquivos e execute os comandos abaixo:

Set-ExecutionPolicy RemoteSigned
.\dsa-start-n8n.ps1
